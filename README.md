A Python 3.13 standard-library program writes one original self-roast to `entry.txt`.
Run `MAKEFUN_OUTPUT_DIR=out python3 main.py`; the default output directory is `/output`.
The output is one UTF-8 line, 94 characters and 94 bytes.
